The runtime archive contains the unmodified official Node.js 26.3.1 executable
and its LICENSE. Official archive digests are pinned in runtime-lock.json.

Linux arm64 also contains the unmodified libatomic.so.1.2.0 binary from Debian
libatomic1 12.2.0-14+deb12u1, stored as the regular file node/lib/libatomic.so.1.
Only the private Node process uses this library path. No system package or
library is installed or replaced.
